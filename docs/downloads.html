The HEvOD data are distributed as a single Microsoft Excel workbook. The first sheet, "READ ME", is a meta information sheet describing the purpose of the dataset and every column used in the other sheets. Each of the remaining sheets holds the evacuation orders (and state-of-emergency declarations) for one hurricane and is named after the event and its year.

You can download the full workbook with every hurricane, or a partial download of the hurricanes you pick (one workbook per hurricane, each with the README sheet). Choose an option below to continue.

You will receive the file containing the READ ME sheet and one sheet for each of the hurricanes.

.xlsx / .zip

Leave the name blank to use “selected_hurricanes”. One hurricane gives an .xlsx file; several give a .zip with one workbook per hurricane.
