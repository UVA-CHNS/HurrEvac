# HEvOD: Hurricane Evacuation Order Database

This is a web application for visualizing evacuation orders issued for hurricanes that impacted the US from 2014 onwards. The site is static (plain HTML, CSS and JavaScript, with [Plotly.js](https://plotly.com/javascript/) drawing the map). The last update is on Nov 23rd, 2026.

The live dashboard can be viewed at: https://uva-chns.github.io/HurrEvac/

## Instructions for running locally

The website itself only needs the `docs` folder. The Python environment in steps 2-3 is needed only to rebuild the data (see "Adding new hurricane evacuation data").

1. Clone this repo:
   ```
   git clone https://github.com/UVA-CHNS/HurrEvac.git
   cd HurrEvac
   ```
2. Create a virtual environment (Python 3.9 or newer):
   ```
   python -m venv venv
   ```
3. Activate it and install the requirements:
   ```
   venv\Scripts\activate            (Windows)
   source venv/bin/activate         (macOS / Linux)
   pip install -r requirements.txt
   ```
4. Start the local server from the repo folder:
   ```
   cd docs
   python -m http.server 8000
   ```
   Windows users can instead double-click `run_local.bat` (macOS / Linux: `./run_local.sh`), which does the same.
5. Open http://localhost:8000/index.html in a browser. Keep the terminal open while you use the site.

Opening the HTML files by double-clicking does not work, because browsers block loading the data files from `file://`. An internet connection is needed for the map tiles.

## Folder description

```
docs/        website files after processing (HTML, CSS, JS, data)
pipeline/    rebuilds docs/data from the raw workbook (notebook + preprocessing script)
```

## Adding new hurricane evacuation data / processing raw data

1. Add a new sheet to `pipeline/data/HEvOD_2014-2026_Website.xlsx`, named `YEAR Name` and formatted like the existing sheets.
2. Activate the virtual environment (steps 2-3 above), go to the `pipeline` folder and open the notebook:
   ```
   cd pipeline
   jupyter notebook rawData_processing.ipynb
   ```
   Run all cells. Section 1 cleans the evacuation orders and Section 2 scrapes the public advisory times from the NHC archive. The results are written to `pipeline/data/temp/`.
3. Next, in the `pipeline` folder, run:
   ```
   python hevod_preprocess.py
   ```
   This writes the site's data files to `docs/data/`. Add `--skip-workbooks` to skip rebuilding the per-hurricane download workbooks. If the script reports a new Order Type, add it to `ORDER_TYPE_STYLES` in `pipeline/config.py` and run it again.
4. Start the local server (step 4 above) and refresh the page (Ctrl+F5) to check that the new hurricane appears.

## Note

`docs/data` already contains the processed data. These files are intermediate files generated by `pipeline/hevod_preprocess.py`: the map data is split into one small file per hurricane, which reduces loading time because the browser does no heavy processing. Do not edit them by hand; regenerate them with the steps above.
